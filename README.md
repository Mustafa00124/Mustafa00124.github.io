# Mustafa's Personal Website

A philosophical and thoughtful personal website for Mustafa Siddiqui, AI researcher and engineer.

## 🎨 Design Philosophy

The website embodies the theme of "Philosopher in sunlight" with:
- **Light Mode**: Soft orange accents (#F8B84E), cream backgrounds (#FFFDF8)
- **Dark Mode**: Charcoal backgrounds (#0B0C10), neon orange highlights (#FF6B35)
- Thoughtful animations and subtle interactions
- Clean, readable typography with generous spacing

## 🚀 Features

- **Responsive Design**: Optimized for all device sizes
- **Dark/Light Mode**: Smooth transitions with local storage persistence
- **Interactive Elements**: 
  - Tilted portrait image that straightens on hover
  - Typewriter effect for the hero text
  - Animated SVG illustrations
  - Particle background in dark mode
- **Smooth Animations**: Framer Motion for scroll-triggered animations
- **Accessibility**: Semantic HTML and keyboard navigation

## 🛠️ Tech Stack

- **React 18** with Vite for fast development
- **Tailwind CSS** for styling and theming
- **Framer Motion** for animations
- **Typed.js** for typewriter effects
- **tsParticles** for particle animations
- **Lucide React** for icons

## 📦 Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## 🎯 Sections

1. **Hero**: Split-screen layout with portrait and typewriter text
2. **Who I Am**: Personal philosophy and background
3. **Why I Work on AI**: Motivation and purpose
4. **My Kind of People**: Values and collaboration preferences
5. **How I Think**: Tennis, strategy, and learning philosophy
6. **Connect**: Contact information and social links

## 🎨 Customization

The color scheme and animations can be customized in:
- `tailwind.config.js` - Color palette and animations
- `src/index.css` - Custom CSS classes and utilities
- Individual components for specific styling

## 📱 Responsive Design

The website is fully responsive with:
- Mobile-first approach
- Flexible grid layouts
- Optimized typography scaling
- Touch-friendly interactions

## 🌙 Dark Mode

Dark mode includes:
- Particle background animation
- Adjusted color palette
- Smooth transitions
- Local storage persistence
